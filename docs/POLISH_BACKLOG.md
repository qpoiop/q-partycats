# PARTY CATS — 자동 다듬기 백로그

목표: 이동·충돌·액션의 **모든 동작을 유연하고 자연스럽게**, 전투 퀄리티를 **파티 애니멀즈급**으로.
30분 크론이 이 파일을 읽고 **최우선 미완료 1건**을 골라 구현 → 빌드 → (가능하면) 브라우저 검증 → 커밋/푸시(production 자동배포) → 이 파일 갱신.

규칙:
- 한 사이클 = **작고 안전한 개선 1건**. 항상 빌드 green 유지.
- 매직넘버 땜질 금지 — 구조적으로. 뼈 회전값은 브라우저에서 눈으로 확인하며 튜닝.
- 콘솔 에러 0.
- 완료 시 `[x]` 체크 + 무엇을 했는지 한 줄. 새로 발견한 이슈는 아래에 추가.

## ★ 최우선: 액티브 랙돌 (파티애니멀즈 자연스러움) — 유저 지시
근본원인: 클립 2개 + 단일 캡슐 + 절차적 뼈회전 = canned/뻣뻣. 파티애니멀즈는 액티브 랙돌+풍부한 애니.
방침: **게임플레이는 단일 캡슐 authority 유지**(물리/넷코드/성능 안전), **비주얼 스켈레톤을 물리 스프링으로 구동**해 흐물·무게감·반응성. 단계적, 매 사이클 빌드 green.
- [x] Phase 1: 몸통 lean을 언더댐프 각도 스프링(BODY.wobble*)으로 → 이동 오버슈트/정착(물컹) + 히트 시 스프링 킥(덜컹 워블). 검증: 안정적, 히트 13° 진동 2회 정착.
- [x] Phase 2: 2차모션 스프링. **머리**(회전 lag ~24° + stride bob) + **꼬리**(뼈트리로 Bone002 체인 식별→BONEMAP.tail, idle 스위시 ~10° + 회전 시 45° 스윙아웃) 완료. 안정 검증. (척추 sway는 필요시 후속.)
- [x] Phase 3: 넉다운 림프 랙돌 — 맞으면 팔다리 에너지flail 대신 loose sprawl+정착, 머리/꼬리 droop. koPose로 blend(쓰러짐→림프→일어남). 검증 안정. head/tail 2차모션은 limp 중 배제.
- [ ] Phase 4: 앞발/뒷발 스프링 IK — 착지/이동 시 다리 접힘·펴짐 물리적으로.
- [ ] Phase 5: 잡기/버둥/던지기에 스프링 반응 연동(잡힌쪽 축 늘어져 버둥).
- [ ] (선택) 만약 스프링으로 부족하면 Rapier 다관절 랙돌(비주얼 전용, 캡슐서 파생, 클라 로컬) 검토.

### 이동 (movement)
- [ ] 가감속/관성 곡선 파티애니멀즈처럼 살짝 물컹하게 (급정거 X). 지금 velocity-spring gain 튜닝. (주의: 수동 g.tick 물리적분 노이즈 심함 → 라이브 감각 필요, 헤드리스 수치측정 부적합)
- [x] 발 미끄러짐 제거 — 앞발 stance 지면속도 실측(timeScale 1 = 2.9u/s) → refSpeed 3.2→2.9, timeScaleMax 2.1→2.4. 재측정 slip: speed3=0.02, speed6.2=0.05 (기존 0.54). 발-몸 속도 동기화.
- [ ] 회전(facing) 시 몸이 자연스럽게 기우는 정도 눈으로 확인(발슬립은 해결됨).
- [x] 공중 제어감 + **착지 스쿼시** — 낙하 착지 시 하강속도 비례 compress-recover (peak squash 0.21 검증).

### 충돌 (collision)
- [x] 고양이끼리 파바박 지터 제거 — force-based 이동으로 이미 해결 확인 (4마리 밀집 avg speed 0.92 수렴, velocity 급변 0).
- [x] _grindShove 세기 튜닝 — 검증 완료: 안 저항 봇을 ~2.9m/s로 밀며 gap 1.32 유지(발사 아님, 그라인드 느낌). 현 세기 적절.
- [ ] 모델 상호 겹침(클리핑) 최소화 — 캡슐 반경 vs 비주얼 폭.

### 액션 (actions)
- [x] 주먹 타이밍 = 스윙 동기화 — 기존 즉시히트 → 윈드업 후 스윙 중간(punchStrikeFrac 0.4)에 컨택. 실측 히트 0.128s(예상 0.136s). 앞발 나가면서 맞음, 회피 가능. Actions.punch→punchStrike 분리.
- [x] 잡기 팔로 끌어당기는 비주얼 — 잡은쪽 앞발이 tug 케이던스로 당김(armPulse~2.0 검증) + 홀드포인트 펄스. 
      메모: 피해자 물리 딸림은 임계감쇠 스프링이 흡수해 0.08u에 그침(스프링 약화는 잡기 안정성 위험 → 안 함). 팔 모션이 주 비주얼.
- [x] 던지기/넉백 궤적 트레일 — 세게 날아가는 넉백(sp>5, 공중)에 speed-streak 방출. 던지기 검증 15개 트레일. 킥/펀치런치에도 일반화.
- [x] 잡기 버둥 연타 손맛 — 연타(addStruggle)마다 flail 스파이크(_mashPulse, GRAB.mashPulse 0.4) + 로컬은 미세 셰이크. 검증: mash→0.4→5프레임 감쇠. 버그수정: carried victim은 preStep early-return이라 감쇠를 _carriedTick에 넣음.
- [x] 슬라이딩 = 트립 태클로 차별화 — 미사용 slideStrike(7.5)/slideLift 연결 → 슬라이딩 적중 시 넉다운(트립) 발생. 검증: 넉백 5.6u + 넉다운 0.53. 대시=밀기, 슬라이딩=넘어뜨리기, 날라차기=킥으로 구분.
- [x] 대시 잔상 이펙트 — 대시 중 매 프레임 speed-streak 방출(잔상 꼬리, 12~18개 동시생존 검증). 개별 불투명도↓로 겹침 자연스럽게. 초록 지면 위 가시성 보통.

### 넉백/기절 (knockback / knockdown)
- [x] 기절 포즈 = **옆으로 쓰러져 눕기** (앞축 90° 롤 + 폭절반 0.7 리프트) → 머리 땅에 안 박힘, 평평하게 누움 검증. koPose 램프로 쓰러짐/일어남 부드럽게(스냅 없음).
- [x] 넉백 거리 밸런스 검증 — 주먹 넉백 1.92u/0.35초, 적절함(너무 멀리 X). 대시/킥은 추후 재확인.
- [x] 대시/날라차기 넉백 거리 재조정 — 측정결과 날라차기 30u(아레나 지름 2배!)로 과함 → dashStrikeAir 8.5→5.5, ground 5.5→4.0, airDrag 0.9→2.0. 재측정: 주먹 1.77 / 대시 4.76 / 날라차기 10.16u (팝업 2.4). 중앙서 즉사 아님.
- [x] 히트 계층 분리 — 검증 중 발견: 주먹(punchKnock 9 ≥ 임계 5.5)이 매번 풀 넉다운시켜 "스태거" 계층이 없었음. hit()에 stagger 옵션 추가 → 주먹=스태거만(넉다운0, tumble 0.83, ~1.8u 밀기), 슬라이딩/킥=눕힘(넉다운). 가벼운히트=비틀/무거운히트=넉다운 계층 실현.

### 리그/모션 품질 (rig quality)
- [ ] 걷기/달리기 다리 모션 눈으로 튜닝.
- [x] 잡힌 쪽 확실히 공중에 들기 — 측면뷰 검증 결과 스프링 sag로 feet 0.69만 떠서 옆에 앉은 것처럼 보였음. holdHeight 0.95→1.35(sag ~0.6 감안). 검증: groupY 0.69→1.1, 확실히 들어올림. 잡은쪽은 뒷발로 서서 앞발 뻗어 잡는 자세 OK.

### 맵/UI (map / ui)
- [x] 맵 허접함 원인 = forest_house.glb가 죽은나무+전봇대+잔해로 렌더(집 아님, 정크). 제거하고 절차적 통나무집(빨간지붕+창) 랜드마크로 교체. 잔디 tuft(뾰족 스파이크)→짧고 다양한 클럼프 + 색색 꽃점. 검증 스샷.
- [x] 로비 모델 애니메이션 — (1)model.position.y에 _baseY 누락돼 로비캣도 가라앉던 것 수정(발 잘림 해결). (2)뻣뻣한 rear-up-wave 반복→차분한 숨쉬기 bob + 4.5s마다 부드러운 손흔들기+살짝 hop. 검증 스샷.
- [x] 맵 지면 깊이감 — 플랫폼 top에 월드좌표 저주파 노이즈로 초록 톤 패치(셰이더, 추가메쉬/물리 무관). 균일 평면 → 밝고 어두운 잔디 변화. 둔덕과 함께 "평면같음" 개선.
- [x] HUD 모바일 폴리시 — 모바일 가로(844×213) 점검. 플레이어 상태카드 4개가 좁은 폭에서 wrap→둘째줄로 세로낭비 발생 → landscape 짧은높이 미디어쿼리에 컴팩트 카드(nowrap+축소). 검증: 4개 한 줄, 전부 뷰포트 내. (kbHint는 이미 pointer:coarse로 실터치 숨김 확인.)
- [x] 봇 AI 공격성↑ — 케이던스 0.9→0.65s, punch 0.7→0.82, grab 0.3→0.4, 가장자리 타겟 마무리(finisher), **안전가드 날라차기 콤보**(착지지점 아레나 내부일 때만). 11s self-play 4마리 전원 생존(자멸0) 검증.
- [~] 봇 마무리 의도 개선(부분) — 타겟 안쪽 플랭킹(공격이 바깥으로 밀도록) + 잡으면 림까지 끌고가 던지기. 자멸 0 확인, 동작 안전.
      다만 헤드리스 봇대봇 24s KO 여전히 0(엣지방문 0): 근본원인=의도적 낮은 넉백+엣지회피로 아무도 림 도달 못함. 완전해결은 넉백↑(플레이어 느낌 훼손) or 맵축소(유저 거부)라 안 함. 라운드는 타임캡(45s)이 정리 + 사람 참여 시 카오스로 링아웃 발생. 현 상태 수용.
